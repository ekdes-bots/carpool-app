# 🚗 Weekly Carpool Coordinator

A lightweight, real-time web application built to streamline weekly sports carpool planning and driver assignments across multiple families.

---

## ✨ Features

- **⚡ Real-Time Cloud Sync:** Uses Firebase Realtime Database so changes update live across all devices instantly without refreshing.
- **📱 Mobile-First Design:** Optimized for seamless use on iOS (Safari) and Android (Chrome).
- **🚗 Automatic Seat Allocation:** Intelligently groups attending kids into available cars, ensuring driver parents always keep their own kids in their vehicle.
- **📋 One-Click Text Summary:** Generates a formatted text message summary of driver assignments and car rosters ready to paste directly into group chats.

---

## 🛠️ Built With

- **Frontend:** Plain HTML, CSS, JavaScript (Single-file `index.html`)
- **Database:** Firebase Realtime Database
- **Hosting:** GitHub Pages

## 📲 How Parents Can Save as a Phone App

For one-tap access on your home screen:

###  iPhone (Safari)
1. Open the website link in **Safari**.
2. Tap the **Share** icon (square with an up arrow).
3. Scroll down and tap **Add to Home Screen**.
4. Tap **Add**.

### 🤖 Android (Chrome)
1. Open the website link in **Google Chrome**.
2. Tap the **Three Dots menu** in the top right corner.
3. Tap **Add to Home screen** (or **Install app**).
4. Tap **Add**.

---

## 📋 Weekly Coordinator Workflow

1. **Sign-Ups:** Parents select their kid's attendance for upcoming practice sessions and claim driver slots by **Sunday 8:00 PM**.
2. **Review:** Check that all practice legs have sufficient driver coverage and seat capacity.
3. **Share:** Click **📋 Copy Summary for Text** and paste the final weekly schedule into the group chat.
4. **Reset:** At the start of a new week, click **🔄 Reset for New Week** to clear driver assignments while preserving standard car seat capacities.
